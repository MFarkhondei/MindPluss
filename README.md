# MindPluss

نسخهٔ وب فارسی و انگلیسی ابزار نقشهٔ ذهنی؛ اقتباس از [Mind Cleaner](https://github.com/raminturne/Mind-Cleaner)، با حفظ مجوز MIT.

## قابلیت‌ها

بوم آزاد، شاخه‌های چهارجهته، چیدمان خودکار، یادداشت، کارهای انجام‌دادنی، رنگ، جمع‌کردن شاخه، جست‌وجو، بازگشت/انجام مجدد، حالت تمرکز، پوستهٔ روشن و تاریک، پیوست و ضبط صدا، خروجی PNG و Markdown و JSON و تولید نقشه با کلید API شخصی.

## اجرا

به Node.js نسخهٔ ۲۰ یا بالاتر نیاز دارد؛ هیچ وابستگی npm لازم نیست.

```sh
npm start
npm test
```

نشانی محلی: http://127.0.0.1:4173

## استقرار

پوشهٔ پروژه را در Vercel بارگذاری کنید. تنظیمات در `vercel.json` است؛ Framework برابر Other و Output Directory برابر `public` است. ساخت نیاز ندارد.

## داده‌ها و هوش مصنوعی

نقشه‌ها در localStorage همین مرورگر ذخیره می‌شوند و میان دستگاه‌ها همگام نمی‌شوند. برای پشتیبان‌گیری خروجی JSON بگیرید. فایل‌ها در خروجی JSON گنجانده می‌شوند؛ حداکثر اندازهٔ هر پیوست ۴ مگابایت است و ظرفیت مجموع به فضای مرورگر وابسته است. شکست ذخیره‌سازی با پیام خطا نشان داده می‌شود.

کلیدهای API فقط در حافظهٔ صفحه نگه داشته می‌شوند و با بازنشانی صفحه پاک می‌شوند. درخواست‌های ارائه‌دهندگان شناخته‌شده از مسیر سروری `/api/ai` به آدرس ثابت همان ارائه‌دهنده هدایت می‌شوند؛ کلید در سرور ذخیره یا ثبت نمی‌شود. آدرس سفارشی مستقیماً از مرورگر فراخوانی می‌شود و به پشتیبانی CORS نیاز دارد. سرویس محلی روی HTTP ممکن است از سایت HTTPS قابل دسترسی نباشد. هیچ کلید یا حساب پیش‌فرضی ارائه نمی‌شود. قابلیت تولید هوش مصنوعی بدون کلید واقعی قابل آزمایش نهایی نیست.

کد اصلی رابط: Mind Cleaner contributors، ۲۰۲۶. مجوز اصلی در `LICENSE` نگه داشته شده است.

## ذخیره مستقیم در فایل OneDrive

در Chrome یا Edge و روی HTTPS یا localhost، گزینهٔ «ذخیره مستقیم در فایل» را بزنید و فایل JSON را داخل پوشهٔ OneDrive بسازید. همهٔ نقشه‌ها و پیوست‌ها خودکار در همان فایل ذخیره می‌شوند؛ در این حالت فضای کاری در localStorage نوشته نمی‌شود. کلیدهای API در فایل ذخیره نمی‌شوند.

پس از باز کردن مجدد برنامه، «باز کردن فضای کاری» را بزنید و همان فایل را انتخاب کنید. فضای کاری فعلی با محتوای فایل جایگزین می‌شود. پیش از بستن صفحه منتظر وضعیت ذخیره‌شده بمانید. وضعیت ذخیره، پایان نوشتن فایل را نشان می‌دهد؛ همگام‌سازی ابری با برنامهٔ OneDrive است.

از ویرایش هم‌زمان روی چند دستگاه خودداری کنید. اگر تغییر خارجی فایل تشخیص داده شود، ذخیره متوقف می‌شود؛ ابتدا از نقشه‌های ویرایش‌شده خروجی JSON بگیرید و سپس فایل را دوباره باز کنید. باز کردن و ذخیرهٔ JSON قبلی همچنان برای انتقال دستی یک نقشه در دسترس است.
